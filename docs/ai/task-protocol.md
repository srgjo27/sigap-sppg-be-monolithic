# AI Task Protocol

Use this protocol for non-trivial OpenCode tasks.

## 1. Understand

Identify the user outcome and acceptance criteria.

## 2. Discover

Inspect the repository and nearby AGENTS.md files. Find similar implementations.

## 3. Design

Use the architect specialist when boundaries or trade-offs are non-trivial.

## 4. Implement

Make the smallest coherent change.

## 5. Verify

Run focused tests, formatting, and broader checks when practical.

## 6. Review

Use the reviewer and security specialist when risk warrants independent review.

## 7. Document

Update stable docs or ADRs when architecture/public behavior changes.
